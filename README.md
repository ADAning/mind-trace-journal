# 心迹 Mind Trace

> 一个以对话记录、个人状态观察和周期回顾为核心的 Obsidian 插件。

心迹希望把零散的感受整理成可以长期回看的个人轨迹：用几分钟完成一次引导式记录，在本地保存为 Markdown，并通过趋势、主题和周报回看近期发生的变化。

当前版本为 **0.1.0**。

## 主要功能

- 统一主页面：主页、记录、报告、轨迹四个模块在同一页面内切换，随时从任意页面开始记录。
- 引导式日记：从心情、精力和压力自评开始，通过简短问答生成日记。
- 结构化回顾：保留日记正文、事件图谱、智能切片、反思洞察、微行动和自我问题。
- 事件图谱：保存日记时先提取即时事件，每日日记直接展示完整事件账；生成周报前再以整个自然周联合校准事件类型、论元角色、实体名称和明确关系，并分别写回每天。周报记忆星图按照事件与实体的连接关系自动布局，选择节点后再查看日期、时间和完整上下文。
- 个人观测台：心情日历、上一周回顾、7/30/90 天状态趋势（心情/精力/压力独立成图，自评实线/AI 虚线）、主题、切片类别与最近事件。
- 历史与回望：在正文、事件及其元素、主题、切片、反思和原始问答中进行本地全文检索，并按日期、主题与状态重新发现旧记录。
- 自动周报：达到记录门槛后，为最近一个完整自然周生成结构化回顾。
- 轨迹：通过日历、日记与本地全文检索回看过去。
- 专用阅读页面：日记和周报默认以心迹页面展示，同时保留原始 Markdown 编辑入口。
- 多模型支持：支持 OpenAI、Anthropic、Gemini、Kimi、DeepSeek、Qwen 和 OpenAI-compatible 服务。
- 隐私门：可选。可以为心迹页面设置本地密码锁，并在一段时间后自动锁定；也可以暂不设置，直接进入。
- 本地优先：日记和报告均保存在你的 Obsidian 仓库中，不依赖额外数据库。

## 安装

目前请通过 GitHub Release 手动安装：

1. 下载最新 Release 中的 `main.js`、`manifest.json` 和 `styles.css`。
2. 在 Obsidian 仓库中创建目录：

   ```text
   <你的仓库>/.obsidian/plugins/mind-trace-journal/
   ```

3. 将三个文件放入该目录。
4. 重新加载 Obsidian。
5. 在“设置 → 第三方插件”中启用“心迹”。

最低 Obsidian 版本为 **1.11.5**。

## 开始使用

1. 打开心迹设置，选择日记保存目录。
2. 选择模型服务并选择或填写模型名称；全新安装时若 Secret Storage 中已有密钥，默认选择名称排序第一的密钥并使用 Gemini（`gemini-3.1-flash`）。
3. 使用 Obsidian Secret Storage 选择 API Key。
4. 点击左侧功能区的日记图标，进入心迹首页。
5. 选择日期并开始记录。

所有配置都会自动保存，插件重新加载后无需重复设置。

默认情况下，日记保存在设置的日记目录中，周报保存在：

```text
<日记目录>/报告/周报/YYYY-MM-DD--YYYY-MM-DD.md
```

## 支持的模型服务

插件支持以下 LLM 服务商，所有服务商都在设置中提供模型选择；Kimi、DeepSeek 和 Qwen 提供常用模型预设，其余服务商可直接填写其支持的模型 ID。OpenAI-compatible 可用于 Ollama、vLLM、LM Studio 等本地或自建服务。

| 服务商 | 默认模型 | 可选预设 | 默认 Base URL |
| --- | --- | --- | --- |
| OpenAI | `gpt-5-mini` | 直接填写模型 ID | — |
| Anthropic | `claude-sonnet-4-5` | 直接填写模型 ID | — |
| Gemini | `gemini-3.1-flash` | 直接填写模型 ID | — |
| Kimi | `kimi-k2.6` | `kimi-k3`、`kimi-k2.6` | `https://api.moonshot.cn/v1` |
| DeepSeek | `deepseek-v4-flash` | `deepseek-v4-flash`、`deepseek-v4-pro` | `https://api.deepseek.com` |
| Qwen | `qwen3.7-plus` | `qwen3.8-max`、`qwen3.7-plus`、`qwen3.7-flash` | `https://dashscope.aliyuncs.com/compatible-mode/v1` |
| OpenAI-compatible | 需填写 | 直接填写模型 ID | `http://localhost:11434/v1` |

Base URL 都可以修改，以支持不同区域、云厂商专属地址或代理服务。插件不会自动切换模型或开启、关闭深度思考；需要使用其他模型或接口区域时，请直接修改模型 ID 或 Base URL。API Key 与所选服务商、区域必须匹配。

## 自动周报

- 只检查最近一个已经结束的周一至周日。
- 默认至少需要 3 个不同的记录日，可以在设置中调整为 3–7 天。
- 每周默认最多保留 50 件事件，记忆星图默认同时显示 20 件；两个上限都可以在设置中调整，完整事件始终保留在事件账中。
- 同一应用会话对同一周期最多自动尝试一次。
- 不会批量回溯历史周报，也不会自动覆盖已有报告。
- 当源日记晚于报告更新时，会提示报告可能已经过期。

周报中的数值由本地日记计算。AI 负责整理文字观察，不应被视为心理或医学诊断。

日记叙述者本人统一使用人物实体“我”，不会抽取为“用户”。已有数据中名称精确为“用户”的人物节点会立即按“我”显示，并在下次保存事件或执行周级校准时写回规范名称；“插件用户”等具体群体名称不受影响。

周报生成或刷新前会把同一自然周内尚未人工确认的事件作为一个请求发送给当前模型，统一校准后分别写回每天；在事件编辑器中保存过的会话会标记为人工确认，之后不会被自动覆盖。写回前会检查日记是否在模型处理期间发生修改，检测到冲突时停止写回和周报生成。

## 数据与隐私

- 日记、周报和分析来源文件保存在本地 Obsidian 仓库中。
- 生成个性化追问、日记或周报时，相关记录内容会发送到你主动配置的模型服务。
- 周级事件校准只发送所选周内的日记正文、切片、日级候选事件和人工保留事件，不发送原始问答。
- 心迹不会主动收集使用分析或遥测数据。
- 历史检索与回望推荐完全在本地执行，正文索引只保存在当前内存中，锁定心迹或退出 Obsidian 后即清除。
- API Key 通过 Obsidian Secret Storage 管理，不写入日记文件；插件不再读取系统环境变量。
- 密码锁用于保护心迹阅读界面，**不会加密磁盘上的 Markdown 文件**。需要磁盘级加密时，请使用操作系统或同步服务提供的加密能力。

使用第三方模型前，请同时阅读对应服务商的数据与隐私政策。
